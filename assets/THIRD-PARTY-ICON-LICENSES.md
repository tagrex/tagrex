# Third-party icon licenses

The Online media-type badge can draw its glyphs from several icon families,
selectable in **Settings › LAB › Media glyphs** (#340). The glyph SVGs are
inlined in `app/ui/js/mediaglyphs.js`. Each external family is used under the
MIT License, reproduced verbatim below.

- **Phosphor Icons** — the `phosphor-thin` / `phosphor-light` / `phosphor-regular`
  sets (vinyl / cd / cassette / waveform / music-note). <https://phosphoricons.com>
- **Tabler Icons** — the `tabler` set, and the vinyl of the `ours-plus` set.
  <https://tabler.io/icons>
- **Bootstrap Icons** — the `bootstrap` set. <https://icons.getbootstrap.com>

The `ours` and (bar its Tabler vinyl) `ours-plus` glyphs are the project's own
work; only the external glyphs above carry these licenses.
