Rename by mask

Placeholders: %artist% %title% %album% %albumartist% %track% %disc% %side% %year% %genre% %composer% %publisher% %bpm% %isrc% %key% %catalognumber% %media%. Wrap optional parts in [brackets] — dropped whole when empty, e.g. %album%[ (%year%)]. Track numbers pad to two digits; set another width with %disc:2%. On vinyl/cassette %side% is the side letter (A/B…), so %side%%track:1% gives A1; it's blank on other media.

Reorganize into folders

Use / (or \) to separate folders. Optional parts go in [brackets] and vanish when empty. Paths are built under the opened library; tag values can't introduce a folder, only separators in the pattern do.
