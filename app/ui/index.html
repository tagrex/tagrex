Tags from the file name

The same placeholders RENAMER uses, read the other way. Add / (or \) to reach into the folders — %albumartist%/%album%/%track% - %title% — and one folder level is matched per separator. Wrap optional parts in [brackets], and use %skip% for a run of text that maps to no tag. Write a width out to split values that run together: %disc:1%%track:2% reads 101 as disc 1, track 01. A name that doesn't fit the pattern is left alone; %side% can't be read back, and a value the field can't hold (a vinyl A1 as a track number) is flagged in the preview instead of being written. Values come out as the name spells them; the rules under the wand above tidy them up as part of the same press.
